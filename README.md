# Городская лента — статья о тренере Алексе

Готовый одностраничный статический сайт для детективного квеста. Без сборщика и сервера.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий (например `gorod-news`).
2. Загрузите в **корень репозитория** `index.html`, `style.css`, `script.js` и папку `assets` целиком. Не загружайте их как вложенную папку `gorod-sport-news`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через короткое время страница будет доступна по адресу `https://ваш-логин.github.io/gorod-news/`.

Для обновления текста редактируйте `index.html`. Кнопки «Поделиться» и «Печать» работают; на телефоне есть мобильное меню. Остальные рубрики ведут к разделам на этой странице.

### Важно

Сайт и публикация полностью вымышлены и предназначены только для игры. Фото персонажа Алекса — иллюстрация из созданных для квеста материалов.
